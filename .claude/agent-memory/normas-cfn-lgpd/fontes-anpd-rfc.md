- Enunciado CD/ANPD nº 1/2023 (22/05/2023): dados de crianças e adolescentes nas bases do art. 7º ou 11, com o melhor interesse prevalecendo (https://bibliotecadigital.mj.gov.br/bitstream/1/10215/2/Enunciado_ANPD_2023_1.html), conferido em 24/11/2026.
- RFC 8058 (https://www.rfc-editor.org/rfc/rfc8058.html), conferida em 24/11/2026: uma URI HTTPS; `List-Unsubscribe-Post: List-Unsubscribe=One-Click`; DKIM cobrindo os dois cabeçalhos (h=); POST sem cookie; o remetente não redireciona. A doc do Resend não diz se o DKIM cobre cabeçalhos personalizados: a conferir num e-mail real ("Mostrar original"). Ver [[pendencias-consulta-crn3]].
